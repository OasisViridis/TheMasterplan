# Triage 标签映射

| Matt role | 本仓库标签 |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

状态含义、任意成员评估权限及认领条件以
[Core Workflow §1.2](../../core/workflow.md#12-issue-准备与认领) 为准。
`bug` / `enhancement` 是分类。切换状态时移除旧状态，保留无关分类和标签。
