# 聚合授权可以覆盖受约束的派生发布候选

2026-10-12 的全流程审阅中，人类选择允许一次“合并并发布”授权覆盖明确列明的
Squash Merge 结果。合并会改变 SHA；如果所有变化都无条件作废授权，即使内容
符合审核预期，也无法完成一次批准的完整事务。

授权绑定 PR head、审核基线、预期结果内容树、目标 Tag、Notes 内容和允许转换。
合并前核验当前 head/base 与平台门，合并后固定实际 main SHA、确认合并记录与
结果树，再重新验证。树相同只是一个必要条件，不是复用任意授权的充分条件。
未列明转换、额外提交、远端移动、内容或范围变化、验证失败均停止并重新审核。

保留直接批准既有 main 完整 SHA 的 tag-only 路径。放弃“每次合并后必再批准发布”
作为唯一模型，以减少重复打断；代价是必须为派生路径维护严格的身份与结果证据。

2026-10-12，人类在定稿会话以“定稿”接受本决定；定稿时候选失效规则尚未修改。
本次实施候选已更新 Core 与相关 Profile 的受约束转换规则；尚未合入或发布。
实施范围与验收见[全流程修改计划](../workflow-audit-and-change-plan.md)。
