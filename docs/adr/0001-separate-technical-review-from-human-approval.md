# 技术审阅与人类批准分离

多人协作模式的设计讨论已确认：技术审阅可以由 Agent 完成，PR 批准由人类负责。
将复核正确性、验证与风险的工作交给 Agent，让人类保留接受候选改动的决定权，避免每个 PR 都要求人类重复完成全部技术审阅。
技术审阅结论与人类批准分别记录，项目要求的 GitHub approval、CI 和受保护分支限制继续满足。

审阅 Agent 使用未参与实现的另一个会话，可以由执行者本人发起；独立性按实现参与情况判断。
任意具备批准资格的人类团队成员均可批准 PR，协调人处理争议。
2026-10-11 根据人类纠正移除额外的非作者资格限制，平台保护规则继续满足。

整体设计已于 2026-10-10 经人类确认；本次 PR 将决定落实到 Core、模板与正文
校验。源码落地不代表采用项目已同步、保护规则已配置或真实人类批准已取得。
