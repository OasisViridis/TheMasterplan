# 主动技能协作

> 在知识或方法缺口、关键不确定性出现时按需读取。普通简单任务直接完成。
> 本文随采用包分发；外部技能是可选帮助来源，不是采用依赖。

## 1. 主动求助与技能路由

主动求助是在预见缺口时及时取得方法或事实帮助；技能路由是为这个缺口选择
合适能力；技能协作是给出有限上下文并评估产物。当前任务的交付治理与责任
仍按 [Core Workflow](workflow.md) 执行。

1. 明确当前目标、缺口和影响：缺的是一手事实、复现证据、设计判断、审阅方法
   还是行为反馈？无需等失败，也不为没有缺口的简单任务增加流程。
2. 从当前宿主实际提供的技能中选择。优先使用适合且已可用的 Matt Pocock
   方法技能；其他来源同样可用。名称与简介仅用于定位，读取所选技能的实际
   内容、必要参考和调用说明后再执行，不预读整套技能库。
3. 简短说明缺口和技能如何提供帮助，例如：“原因尚不清楚，我用诊断技能建立
   复现反馈，再依据证据修复。”随后按宿主支持的方式调用；支持原生调用就
   使用原生接口，仅有可读文件则按文件加载并执行实际步骤，如实标明方式。
4. 求助上下文只包含目标、缺口、文件边界、必要证据和期望产物。技能或子代理
   只负责该单元；主代理检查依据、范围和可用性，整合产物并继续当前任务的
   实现、验证和最终 diff 审阅，不把技能建议直接当成已验证结论。

完成求助的条件是缺口得到可核对的证据或产物，并已评估其对当前任务的帮助。
若仍有关键缺口，说明尚缺什么、为什么影响后续工作，同时继续可独立完成的
授权工作；求助完成不等于任务完成。

## 2. 可用性、回退与完整流程

- 技能缺失、不可读或不适合时，改用已可用的替代技能或工具。禁止因求助自动
  安装或更新技能、修改用户技能环境，或把某个技能库设为默认依赖。替代能力
  足够时继续任务；关键缺口确实无法解决时才报告阻碍。
- 区分方法技能与由用户调用的完整流程：前者补足当前任务的方法，后者可能
  包含持续访谈、规格整理、拆票或多任务实施。需要完整流程时简短说明推荐
  理由和启动方式，等待用户启动；已有明确启动授权时按其范围执行。技能的
  导航资料（例如 ask-matt）只帮助选路，不自动启动其推荐的用户流程。
- 依据当前可读内容和实际调用限制作选择，不维护全部上游技能的固定映射。
  一个技能内部提出安装、额外提问、写入或新流程时，先核对当前授权和必要性；
  已确认的目标、测试边界与有效授权无需重复询问。超出范围的建议留作建议。

## 3. 方法示例

以下是可扩展的选择示例，不是必装清单，也不是技能名到任务的强制映射。
实际内容和适合程度优先；合适的其他方法技能也可使用。

| 缺口 | 可选方法示例 | 期望产物与使用方式 |
| --- | --- | --- |
| 一手事实或技术依据不足 | research | 附来源的事实与不确定性，核对后用于实现判断 |
| 缺陷原因不明、反复尝试无反馈 | diagnosing-bugs | 能复现问题的反馈、原因证据与修复验证 |
| 模块边界或领域术语不清 | codebase-design / domain-modeling | 清晰接口、责任边界或一致术语，按范围整合 |
| 需求符合性或规范风险不确定 | code-review | 固定基线与候选的 diff、需求和规范发现，修复后复核 |
| 回归风险缺少有效反馈 | tdd | 经认可公开边界上的行为测试与失败到通过的证据 |

测试投入与风险相称；为简单可逆修改不强制增加测试。已有 Issue 或会话确认的
测试边界可直接复用。审阅需绑定固定基线与实际候选，候选变化后重新审阅。

## 4. 交付治理与证据

方法求助不改变授权、文件归属、完成合同、独立技术审阅、人类批准或治理所有权。
普通工具、方法技能、PR 或 CI 的存在不自动构成治理移交；只有明确证据表明
外部系统拥有当前任务的生命周期时，才按 [Core Workflow §0](workflow.md#0-治理所有权)
执行现有 `ABSTAINED` 规则。技能不能授予 merge、release、deploy 或其他更高
权限；相应操作仍按 [Core Policy](policy.md) 执行。

AI 技能审阅、主代理自审、机械检查与人类 PR 批准分别记录。未参与实现的另一
Agent 会话可以承担 Core 要求的独立技术审阅，其报告不能替代人类批准。行为
验收记录输入、候选身份、预期、实际结果、技能来源及内容身份、
调用顺序、产物和使用方式。分别标明宿主原生调用、按文件加载后实际执行、
模拟、仅静态检查与未验证；只有实际执行且有证据才记为实际使用。隔离任务
演练只覆盖所测宿主、技能和候选，不证明所有宿主或生产采用项目通过。
